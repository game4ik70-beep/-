# ENGINEERS: Progression — прототип 0.1.0

Авторский мод интерфейса «Инженерный архив» для Minecraft Java 1.21.1 / NeoForge.

## Что уже заложено
- Открытие архива клавишей **O**.
- Пять вкладок технологических направлений.
- Выбор пяти демонстрационных узлов в каждой ветке.
- Панель описания выбранного исследования.
- Переключение на страницы «Задания» и «Чертежи».
- Пиксельная палитра графит / дерево / латунь / янтарь.

## Важно
Это исходный прототип интерфейса, а не законченная система прогрессии. Узлы пока демонстрационные: серверная синхронизация, реальные условия разблокировки, рецепты, награды, сохранение исследований и интеграция с Create/Aeronautics ещё не реализованы.

## Сборка
1. Установить JDK 21.
2. Установить Gradle 8.10.2 или совместимую версию.
3. Открыть папку проекта в IntelliJ IDEA.
4. Выполнить `gradle build`.
5. Готовый JAR появится в `build/libs/`.
6. Положить JAR в папку `mods` клиента/сервера NeoForge 1.21.1.

Для разработки можно запустить `gradle runClient`.

## Управление
В игре нажать **O**. Клавишу можно изменить в настройках управления Minecraft.
